# Application-level baseline; torch selects its matching Triton dependency.
# Not a cross-platform CUDA lock: driver/wheel compatibility is checked by the
# bounded runtime gate. Do not blindly upgrade the inference API on every run.
#
# torch upper bound: 2.13 introduced torch/_native/ops routing (e.g.
# bmm_outer_product) through Triton, forcing a runtime gcc + Python.h compile
# on first inference. Without this pin, pip drifts to the newest torch on
# every reinstall and breaks environments lacking Python dev headers
# (verified incident 2026-10-10). Lower bound 2.6 follows the Qwen3-ASR
# upstream recommendation and keeps older machines/Pythons installable.
# Lift the upper bound only deliberately, then re-run the full preflight acceptance (scripts/setup-qwen-asr.sh).
#
# 版本策略（2026-10-11 全新安装实测确立）：
# - 精确 pin：解析器回溯痛苦（gradio 每台新机多花数分钟试十几个版本）或
#   推理 API 敏感的包，pin 到完整验收（CUDA/Triton + 模型推理）通过时的版本。
# - 推荐范围：兼容面宽的包给 bounded range，避免漂移到未验证的大版本。
